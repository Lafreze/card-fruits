# 水果叠叠乐 · Fruit Stack

三张卡片，一场丰收。把叠层卡牌三消、落点选择和物理合成放进一片手绘果园。

## 这一版

- 完整的浅色果园界面：桌面双栏主页、手机布局、游戏桌面、图鉴、温室、战绩和结算。
- 50 种逐个绘制的卡通水果：圆润轮廓、清晰色块与简洁高光，透明背景，无底部投影。卡牌、物理水果和图鉴共用同一套 WebP 素材，不依赖系统 emoji 字体。52 个功能图标保留 SVG。
- 五种玩法，均可直接选择：**47 关闯关**、**波次无尽**、**8 关 Rogue 远征**、**120 秒限时榨汁**、**每日鲜摘**。
- 五档难度：悠闲（8 格、3.5 秒警戒、得分 ×0.8）、标准（7 格、1.8 秒、×1）、困难（6 格、1.4 秒、×1.4）、大师（5 格、1.1 秒、×1.8）、极限（4 格、0.9 秒、×2.4）。高难度增加特殊牌、果箱压力和天气频率。温室、奇物、波次变异继续在基础数值上生效。
- 限时榨汁以得分为目标、清牌续波，120 秒到自动结算；满槽/爆箱仍可提前结束。倒计时、物理与延迟动作随菜单/后台切换暂停。
- 每日鲜摘在 **UTC 00:00** 换题，同一天相同的关卡、种子、牌阵与特殊牌；固定困难难度、基础道具，禁用温室成长。可重复挑战，按日期保存最佳分；这是本机挑战，不提供联网竞技或防作弊认证。
- 保留三路落点、弹射、狂热、20 种技能与道具、36 件奇物与温室永久成长。

- 新技能：**透视镜**标出最易补齐的一组同果卡，持续 8 秒；**聚果场**将全部同果吸引增强至 2.6 倍，持续 10 秒。每局各有 1 次，温室可增加次数；无有效目标不扣次数，生效期间不会重复消耗。
- 六种随机天气：东风（右漂、得分 ×1.2）、热浪（警戒加速、得分 ×1.5）、磁力潮（吸引 ×2）、糖霜雨（减速、吸引减半、得分 ×1.3）、月光轻飘（重力减半）、回旋风（交替风向）。提前 3 秒预告，持续 10–12 秒，不连续重复；每日鲜摘使用独立固定种子。菜单、后台暂停同时冻结天气与技能计时。
- 合成区图案放大约 15%，保持原有物理尺寸和合成规则；卡牌更清晰、投影更轻，移除牌面序号与常驻教程。手机对局、技能栏和弹窗适配可用视口及安全区域，首页关卡条独立横向滚动。

## 存档：无需数据库

每局结束自动将成绩保存在当前浏览器的 `localStorage`。最佳成绩按玩家名号、模式、难度和每日日期区分，最多保留 500 组；主线优先比较关卡，再比较分数。原版已有的本机关卡、果币、升级和道具键继续沿用。

首页「我的存档」可修改名号、导出或导入 JSON（格式版本 3）。导入前会完整校验，错误文件不覆盖原进度；有效文件覆盖其包含的同名字段。浏览器禁止持久存储时会回退到当前会话，并提示导出。清除浏览器数据、隐私模式结束或换设备都可能丢失本地数据，请先导出备份。

**全球排行榜改为本机战绩榜**，不再需要 PostgreSQL、账号或提交接口。旧数据库里的全球历史成绩没有自动迁移；已有数据库可先自行备份再停用。本次代码不会连接或删除远端数据库。

## 运行

需要 Node.js 22.18+（推荐 24），以及 npm。

```sh
npm install
npm run dev
npm test
npm run build
npm start
```

开发默认端口 5173。生产 Express 同时提供构建产物和 `/api/health`，默认端口 3000，可用 `PORT` 覆盖。也可以直接把 `dist/` 部署在静态托管平台；游戏和存档无需后端。

Railway 保留现有 `railway.json` / `nixpacks.toml` 的构建启动方式。无需 `DATABASE_URL`、数据库服务或数据卷。`index.html` 不缓存，带指纹的构建资源长期缓存，水果文件名包含内容指纹，替换插画后不会命中旧图缓存；功能图标使用短缓存。

## 美术素材

水果成品在 `public/fruit-toons/`，50 份独立绘图描述和统一卡通风格在 `art/cartoon-fruit-prompts.json`，由内置 image_gen 逐个生成。`src/game/fruit-art.ts` 记录带内容指纹的地址，所有展示位置共用。

如需替换素材，将审核后的透明 PNG 按描述文件中的 slug 命名，用 Pillow 执行 `python3 scripts/package-fruit-art.py <PNG目录>`，统一留白并输出 384px 无损 WebP，同时更新地址表和网站图标。脚本只调整尺寸和编码，不绘制阴影。原始 PNG 留在本机 `output/imagegen/source/`，不随网页分发。`npm run art` 仅重新生成界面 SVG 图标，不会覆盖水果插画。

## 验证

`npm test` 覆盖全部关卡的资源与安全消牌路线、碰撞合成、计分和养成曲线，并验证每日种子、难度、计时边界、全部水果素材、本机最佳分、去重及存档校验。浏览器联调覆盖桌面/手机、三消与物理合成、重新开局、暂停、特殊模式和存档界面。

历史设计记录保存在 `DESIGN.md`，以本 README 和当前代码为准。

- 手机对局铺满可用屏幕，竖屏上下排列，横屏左右排列；旋转和窗口变化保留当前对局。
- 遮挡只计算旋转后的圆角牌面，同层按实际绘制顺序判断；光晕、阴影和透明圆角不拦截点击。
- 物理以 120 Hz 固定步进计算，保留滚动与碰撞惯性；普通合成必须接触，合成动画期间保留实体。
- 新增弹力垫（底部弹跳增强 10 秒）与天气仪（清除当前或预警天气），每局基础各 1 次，可在温室升级。
